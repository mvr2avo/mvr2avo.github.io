WINDOWS DESKTOP APP

From MVR to Avolites Titan.

MVR2AVO is a Windows desktop application that reads fixture patch data from MVR files, matches GDTF fixtures to Avolites personalities, and prepares a reviewed patch for Avolites Titan.

LATEST RELEASE v0.1.4 · Windows 10 / 11
WHAT YOU CAN DO

Review the patch before it reaches the desk.

MVR2AVO gives you a clear path from MVR fixture data to a reviewed Avolites Titan patch.

01

Inspect the MVR patch

Check fixture patch details imported from the MVR file before making any changes.

02

Review fixture mapping

Compare each MVR fixture with its matched Avolites library personality.

03

Edit patch information

Adjust patch information, fixture modes, and decide exactly which fixtures are included.

04

Resolve unmatched fixtures

When no automatic match is found, search the Avolites library and select the correct fixture profile manually.

05

Recover from patch errors

If a fixture cannot be patched, MVR2AVO can patch it as a Generic Dimmer while preserving its original patch information. You can then replace it with the correct fixture profile later directly on the Titan console.
