# MVR2AVO

MVR2AVO is a Windows application that converts MVR show files into data usable with Avolites Titan, using fixture information from GDTF.

## Download

**[Download the latest Windows release](https://github.com/mvr2avo/mvr2avo.github.io/releases/latest)**

Each release may include:

- `MVR2AVO-Setup-Windows.exe` — Windows installer
- `MVR2AVO-Portable-Windows.exe` — portable version
- `SHA256SUMS.txt` — checksums for verifying downloaded files
