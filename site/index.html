WINDOWS DESKTOP APP

From MVR to Avolites Titan.

MVR2AVO is a Windows desktop application that reads fixture patch data from MVR files, matches GDTF fixtures to Avolites personalities, and prepares a reviewed patch for Avolites Titan.

Download for Windows ↓ View latest release ↗
LATEST RELEASE v0.1.4 · Windows 10 / 11
  • Inspect MVR patch details.
  • Review the mapping between MVR fixtures and the Avolites library.
  • Edit patch information, fixture modes, and included fixtures.
  • Exclude individual fixtures from the patch.
  • If no automatic match is found, search and select the correct Avolites fixture profile manually.
  • For patch errors, use the Generic Dimmer fallback while preserving patch information, then replace the profile later on the Titan console.
